## Security audit scope

Actual full-tree npm audits are retained before and after remediation. A direct vulnerable YAML dependency was updated to 2.9.0 and moved to development-only. A normal `npm audit fix --ignore-scripts` applied compatible transitive updates without forced majors; remaining advisories still make that audit command exit 1. A clean package-local `npm ci --ignore-scripts` followed by explicit `npm rebuild fs-ext` builds only the required native journal lock; final verification records check and smoke outcomes. No guards/tests were removed to make tests pass.

The remaining dev-toolchain/bundled advisories are not concealed or counted as fixed. In particular, Ganache bundles old dependencies which npm also reports under `--omit=dev` in this lock tree; do not interpret that output as a proof of the runtime import graph. The lane's exported factories do not import Ganache, solc, Graph CLI, Matchstick or YAML. Development inputs are trusted repository sources and synthetic test data; services bind loopback/isolated Docker networks and are removed after tests. Public distribution, untrusted manifest compilation and live operation require a separate dependency/security review. The user has not approved public deployments, funds, source publication or testnet signing.
